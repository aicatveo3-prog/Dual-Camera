# 앞뒤 동시 카메라 (Dual Camera)

전면·후면 카메라를 **동시에** 켜서 두 화면을 한 번에 보여주는 웹 페이지입니다.
설치 없이 브라우저에서 바로 동작하고, 의존성 없는 단일 HTML 파일입니다.

**▶ [바로 열기](https://aicatveo3-prog.github.io/Dual-Camera/)**

> 카메라 API는 **HTTPS에서만** 동작합니다. 위 링크(GitHub Pages)는 HTTPS라서 그냥 열면 됩니다.
> 로컬 IP(`http://192.168.x.x`)로 접속하면 카메라가 켜지지 않습니다.

## 기기별 지원 현황

| 환경 | 동시 실행 |
|---|---|
| 안드로이드 Chrome (갤럭시 탭·갤럭시 폰 등) | ✅ 대부분 가능 |
| iPhone / iPad (Safari) | ❌ 불가 — 번갈아 모드로 자동 전환 |
| 데스크톱 Chrome + 웹캠 2대 | ✅ 가능 |

`getUserMedia()`는 호출 한 번에 카메라 하나만 주므로, 두 번 호출해서 두 개의 스트림을 만듭니다.
두 스트림이 동시에 살아있을 수 있는지는 **OS와 하드웨어**에 달려 있습니다.

- **안드로이드**: Camera2의 동시 카메라(concurrent camera)를 지원하는 기기면 됩니다. 갤럭시 S10 이후, 갤럭시 탭 S 시리즈는 대체로 동작합니다.
- **iOS Safari**: 한 번에 활성 카메라 1개만 허용합니다. 두 번째를 열면 첫 번째가 조용히 죽습니다. 아이폰 기본 카메라 앱은 되지만(네이티브 `AVCaptureMultiCamSession`) WebKit이 웹에 열어주지 않았습니다.

## 기능

- 버튼 한 번으로 전면·후면 동시 실행, 두 화면 분할 표시
- 화면 방향에 따라 분할 방향 자동 전환 (세로 → 위/아래, 가로 → 좌/우)
- **동시 실행이 안 되는 기기는 번갈아 전환 모드로 자동 폴백** — 대기 중인 쪽은 마지막 프레임을 남겨 검은 화면이 되지 않습니다
- 실패 원인을 구분해 안내 (권한 거부 / 기기 미지원 / 다른 앱 점유 / HTTPS 아님)
- 카메라 직접 선택 — 후면 광각·망원 등 렌즈가 여러 개인 기종에서 유용
- 전면 좌우 반전(셀피 뷰) 토글, 분할 방향 고정, 순서 바꾸기, 전체화면
- 화면 꺼짐 방지 (Wake Lock)
- 진단 패널 — 감지된 카메라 목록, deviceId, 지원 여부 확인

## 동시 실행 판정 방식

두 번째 카메라를 열 때 예외가 발생하지 않아도 동시 실행에 실패할 수 있습니다.
특히 iOS는 첫 번째 스트림을 **조용히** 중단시켜서, `try/catch`만으로는 감지되지 않습니다.

그래서 이 페이지는 두 `<video>`의 `currentTime`이 실제로 흐르는지 측정해서 판정합니다.

```
1. 전면 카메라 열기          → 권한 팝업
2. enumerateDevices()        → 권한 후에야 기기 label이 채워짐
3. 후면 카메라 열기
4. 두 화면의 currentTime이 실제로 증가하는지 확인
     둘 다 증가 → 동시 실행 모드
     아니면    → 번갈아 전환 모드
```

## 로컬에서 실행

`localhost`는 HTTPS 예외라 그냥 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

같은 와이파이의 폰에서 테스트하려면 HTTPS가 필요합니다. GitHub Pages 링크를 쓰는 게 가장 간단합니다.
